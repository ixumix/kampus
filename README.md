# Кампус — неофициальный кабинет студента (новая реализация)

Демонстрационный кабинет для номинации «Вайб-кодинг» MGIMO AI Challenge 2026.

**Прототип:** <https://clide-ixumix.msk1.amvera.tech> · аккаунты `belova` / `kampus-anna` и `galiev` / `kampus-timur`.
Все люди, учебные сведения, заявки и документы **вымышлены**. Проект не связан с системами вуза.

Главная польза — быстрые ежедневные действия: **куда и когда идти, что изменилось, какой документ готов**.

## Запуск

Нужен только Python 3.9+ — внешних зависимостей нет, сборки нет.

macOS / Linux:

```bash
python3 -m server
```

Windows (PowerShell), из корня проекта:

```powershell
py -m server
```

Откройте <http://127.0.0.1:4180>. При первом запуске создаётся `data/campus.db` с демо-набором.

| Демо-аккаунт | Логин | Пароль | Что показывает |
| --- | --- | --- | --- |
| Анна Белова, 2 курс, МО | `belova` | `kampus-anna` | идёт пара, следующая с новой аудиторией, готовая справка, перенос и отмена на неделе |
| Тимур Галиев, 3 курс, Экономика | `galiev` | `kampus-timur` | первая пара днём, нет готовых документов, другая неделя |

Демо-время — **понедельник, 16 ноября 2026, 10:15 МСК** (не часы компьютера). После входа оно **идёт**: через 5 минут первая пара закончится сама, следующая станет текущей. Бейдж «Демо-время» на «Сегодня» открывает ползунок дня (07:00–22:00, стрелки — по 5 минут), переключатель «Время идёт» и другие демо-дни; в профиле — готовые моменты: утро до пар, перерыв, вечер, свободная суббота. Для тестов часы замораживаются переменной `CAMPUS_FROZEN_TIME=1`.

### Сводка недели от модели (необязательно)

Без ключа всё работает: абзац «Коротко» собирается шаблоном. Чтобы его писала модель DeepSeek, положите ключ в файл `.secrets/deepseek.key`. Каталог `.secrets/` указан в `.gitignore`, перезапуск сервера не нужен. Ключ можно передать и переменной окружения `DEEPSEEK_API_KEY`.

```bash
mkdir -p .secrets && read -s "k?DeepSeek API key: " && printf %s "$k" > .secrets/deepseek.key && chmod 600 .secrets/deepseek.key && unset k
```

По умолчанию используется модель `deepseek-v4-flash` на `https://api.deepseek.com`. Для посредника с OpenAI-совместимым API адрес и модель задаются в `.secrets/llm.json`, например `{"base_url": "https://api.apikey.fan/v1", "model": "deepseek-flash"}`, или переменными `DEEPSEEK_BASE_URL` и `DEEPSEEK_MODEL`. Клиент отправляет свою подпись `User-Agent` (стандартную подпись Python посредник за Cloudflare отклоняет с ошибкой 502) и отключает у модели «размышления»: для пересказа фактов они не нужны, а без них ответ быстрее. В модель уходят только факты недели, без ФИО и контактов. Ответ с числом, которого нет в данных, отбрасывается. Тесты всегда используют подставную модель и не делают платных вызовов, даже если ключ лежит в `.secrets`.

### Опции сервера

| Флаг | Назначение |
| --- | --- |
| `--port 4180` | порт (по умолчанию 4180; старый сайт на 4173 не затрагивается) |
| `--db путь` | своя база SQLite |
| `--reset` | пересоздать **эту** базу из демо-набора |
| `--stress` | стрессовый набор в отдельной базе `data/campus-stress.db` (логин `stress` / `kampus-stress`) |
| `--dev` | включить `/api/dev/fault` для имитации сбоев (обрыв ответа, падение чтений, истечение сессии) |

## Публикация (хостинг)

В корне есть `Dockerfile`: образ на `python:3.12-slim`, без внешних зависимостей. В образ не попадают `.secrets/`, `data/`, тесты и документы (`.dockerignore`).

| Переменная | Значение в образе | Зачем |
| --- | --- | --- |
| `PORT` | 8080 | порт (хостинг обычно задаёт свой) |
| `CAMPUS_HOST` | 0.0.0.0 | слушать все адреса внутри контейнера |
| `CAMPUS_DB` | /data/campus.db | база SQLite; подключите постоянный том `/data`, иначе заявки и отметки сбросятся при перезапуске (демо-набор создаётся заново сам) |
| `CAMPUS_TRUST_PROXY` | 1 | за прокси хостинга: настоящий адрес клиента для ограничения попыток входа и cookie с `Secure` по HTTPS |
| `DEEPSEEK_API_KEY` | — | необязательно; только в настройках хостинга, никогда в образе или коде |

Режим `--dev` (имитация сбоев) на хостинге не включается.

## Почему такой стек

- **Python stdlib + SQLite**: запуск одной командой на Windows и macOS без установки пакетов; транзакции и сохранность данных; тесты поднимают сервер на временной базе.
- **Preact + htm без сборки**: компоненты и точечные обновления DOM (фокус в формах не теряется), но без node_modules и бандлера. Вся логика и стили — собственные.
- Секретов в клиенте нет: сессия — HttpOnly-cookie, изменяющие запросы требуют CSRF-токен и проверку Origin, пароли — PBKDF2-SHA256.
